# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email milos300399@gmail.com with "SECURITY" in the subject. Once this repository is on GitHub, you can also use its private vulnerability reporting (Security → Report a vulnerability).

Please include:

- what the problem is and where (URL, file or endpoint);
- steps to reproduce it;
- the impact you think it has.

You'll get a reply as soon as possible. Please give a reasonable time to fix the issue before disclosing it anywhere.

## Please don't

- scan, brute-force or load-test the live site or its services;
- access, change or delete data that isn't yours.

## Scope

Only the code in this repository and the site deployed from it are in scope.
